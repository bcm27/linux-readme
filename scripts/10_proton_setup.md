# Proton Setup Instructions for Linux Gaming

Proton is a compatibility layer that allows you to run Windows games on Linux through Steam. Follow the steps below to enable and configure Proton for your gaming needs.

## Steps to Enable Proton in Steam:

1. **Enable Proton:**
   - Open Steam and navigate to `Steam` > `Settings` > `Compatibility`.
   - Check the box for **"Enable Steam Play for supported titles"**.
   - (Optional) Check **"Enable Steam Play for all other titles"** to use Proton for all games.
   - Select the latest Proton version from the dropdown menu (Proton Experimental is recommended for best compatibility).

2. **Restart Steam:**
   - After making the changes, restart Steam to apply them.

3. **(Optional) Install Additional Proton Versions:**
   - In Steam, go to `Library` and search for "Proton".
   - Right-click on a Proton version (e.g., Proton Experimental) and select "Install".

4. **Check Game Compatibility:**
   - Visit [ProtonDB](https://www.protondb.com/) to see how well your games run with Proton and for any additional tweaks that may be necessary.

By following these steps, you can enhance your gaming experience on Fedora 41 with Proton. Enjoy your games!
