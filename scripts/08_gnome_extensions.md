# Useful GNOME Extensions

This file lists some useful GNOME extensions that can enhance your desktop experience on Fedora 41. You can install these extensions from the GNOME Extensions website.

## Recommended Extensions

- [Vitals](https://extensions.gnome.org/extension/1460/vitals/): A system monitor that displays various system metrics in the top bar.
- [Wireless HID](https://extensions.gnome.org/extension/4228/wireless-hid/): Allows you to use your mobile device as a wireless keyboard and mouse.

## Installation Instructions

1. Visit the GNOME Extensions website.
2. Search for the desired extension by name.
3. Toggle the switch to install the extension.
4. Follow any additional instructions provided by the extension for configuration.
